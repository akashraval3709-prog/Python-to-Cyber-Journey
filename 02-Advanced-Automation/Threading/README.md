# ⚡ Race Condition Handling

A Python threading mini project that demonstrates race condition handling using thread locks.

## ✨ Features

- Creates multiple threads
- Demonstrates shared variable access
- Prevents race conditions using `Lock`
- Synchronizes thread execution
- Shows safe counter incrementing

## 🛠️ Technologies Used

- Python
- Threading Module

## 📚 Learning Concepts

- Multithreading
- Thread Synchronization
- Race Condition
- Thread Locking
- Concurrent Programming

# ⏳ Multi Countdown Timer

A Python threading mini project that runs multiple countdown timers simultaneously using multithreading.

## ✨ Features

- Runs multiple countdown timers together
- Uses Python threading
- Demonstrates concurrent execution
- Uses `time.sleep()` for delays
- Waits for all threads using `join()`

## 🛠️ Technologies Used

- Python
- threading module
- time module

## 📚 Learning Concepts

- Multithreading
- Thread Creation
- Concurrent Execution
- Thread Synchronization
- Countdown Logic
