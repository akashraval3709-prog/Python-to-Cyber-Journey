# ⚡ Race Condition Handling

A Python threading mini project that demonstrates race condition handling using thread locks.

## ✨ Features

- Creates multiple threads
- Demonstrates shared variable access
- Prevents race conditions using `Lock`
- Synchronizes thread execution
- Shows safe counter incrementing

## 🛠️ Technologies Used

- Python
- Threading Module

## 📚 Learning Concepts

- Multithreading
- Thread Synchronization
- Race Condition
- Thread Locking
- Concurrent Programming

# ⏳ Multi Countdown Timer

A Python threading mini project that runs multiple countdown timers simultaneously using multithreading.

## ✨ Features

- Runs multiple countdown timers together
- Uses Python threading
- Demonstrates concurrent execution
- Uses `time.sleep()` for delays

- threading module
- time module

# 📥 Multi File Downloader Simulation

A Python multithreading mini project that simulates downloading multiple files simultaneously using threads.

## ✨ Features

- Simulates multiple file downloads at the same time
- Uses Python threading for concurrent execution
- Displays download progress percentage
- Uses custom thread names
- Waits for all downloads to complete using `join()`

- Python
- threading module
- time module

- Multithreading
- Thread Management
- Concurrent Task Execution
- Thread Naming
- Progress Simulation
- Thread Synchronization
