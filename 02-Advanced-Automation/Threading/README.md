# ⚡ Race Condition Handling

A Python threading mini project that demonstrates race condition handling using thread locks.

## ✨ Features

- Creates multiple threads
- Demonstrates shared variable access
- Prevents race conditions using `Lock`
- Synchronizes thread execution
- Shows safe counter incrementing

## 🛠️ Technologies Used

- Python
- Threading Module

## 📚 Learning Concepts

- Multithreading
- Thread Synchronization
- Race Condition
- Thread Locking
- Concurrent Programming
