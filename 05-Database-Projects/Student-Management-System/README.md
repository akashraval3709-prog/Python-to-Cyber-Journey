# 🎓 Student Management System

A Python-based Student Management System that performs CRUD (Create, Read, Update, Delete) operations using MySQL Database.

## ✨ Features

- Create MySQL database automatically
- Create students table automatically
- Insert student records
- Update specific student details
- Display all student records
- Delete student records
- Input validation
- Parameterized SQL queries
- Exception handling

## 🛠 Technologies Used

- Python
- MySQL
- mysql-connector-python

## 📚 Learning Concepts

- MySQL Database Connection
- CRUD Operations
- SQL Queries
- Parameterized Queries
- Exception Handling
- Dictionary Cursor
- Database Commit
- User Input Validation
