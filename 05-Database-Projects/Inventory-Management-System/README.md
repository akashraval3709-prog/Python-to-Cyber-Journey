# 📦 Inventory Management System

A simple Inventory Management System built using **Python**, **Flask**, **SQLAlchemy ORM**, and **MySQL**. This project demonstrates CRUD operations, database management using ORM, and basic inventory handling.

---

## ✨ Features

* Automatically creates the database and inventory table
* Insert multiple product records
* Display all available products
* Find the highest-priced product
* Filter products based on stock quantity
* Automatically restock out-of-stock products
* Sort products alphabetically (A–Z)
* Transaction management with commit and rollback
* Exception handling for database operations
