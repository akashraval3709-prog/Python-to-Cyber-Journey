# 🔐 Flask JSON Login API

🚀 **Live Demo:** [https://flask-json-login.onrender.com](https://flask-json-login.onrender.com)

A simple Flask authentication project demonstrating how to build a JSON-based Login API using **Flask**, **Fetch API**, and **Session Authentication**. This project shows how a frontend can send JSON data to the backend and receive structured JSON responses while protecting authenticated routes.

---

## 📚 Topics Covered

- Flask Routing
- `request.get_json()`
- `jsonify()`
- Session Management
- Login Authentication
- Fetch API
- JSON Request Handling
- JSON Response Handling
- Protected Routes

---

## ✨ Features

- JSON-based Login API
- Fetch API Integration
- Session-based Authentication
- Protected Welcome Page
- User Profile API
- Automatic Redirect after Login
- Unauthorized Access Handling

---

## 🛠 Technologies Used

- Python 3
- Flask
- HTML5
- CSS3
- JavaScript (Fetch API)
