# 🌐 Flask API Response

A simple Flask REST API project demonstrating how to build API endpoints that return JSON responses using `jsonify()`. This example simulates a product database and retrieves product details based on a product ID.

## 📚 Topics Covered

- Flask Routing
- REST API Basics
- JSON Responses
- `jsonify()`
- URL Parameters
- HTTP Status Codes
- Dictionary as Mock Database
- GET Request Handling

---

## 🛠 Technologies Used

- Python 3
- Flask

## ✨ Features

- Retrieve product information using Product ID
- Return structured JSON responses
- Handle successful (`200 OK`) requests
- Handle missing resources (`404 Not Found`)
- Simulate a backend database using Python dictionaries

## 🎯 Learning Outcomes

- Build a simple REST API with Flask
- Return JSON responses using `jsonify()`
- Work with dynamic URL parameters
- Send appropriate HTTP status codes (`200`, `404`)
- Design consistent API response structures
- Understand how backend APIs communicate with frontend applications
