
# 🌐 Flask API Response

A collection of Flask REST API examples demonstrating how to build API endpoints and return JSON responses using `jsonify()`. These examples cover structured API responses, URL parameters, lists, and response metadata.

## 📚 Topics Covered

- Flask Routing
- REST API Basics
- JSON Responses
- `jsonify()`
- URL Parameters
- Response Envelope
- List Serialization
- HTTP Status Codes
- Dictionary as Mock Database
- GET Request Handling

# 01. Product API Response

Retrieve product information based on a Product ID and return a structured JSON response using Flask's `jsonify()`.

### ✨ Features

- Retrieve product details using Product ID
- Return structured JSON responses
- Handle successful (`200 OK`) requests
- Handle missing resources (`404 Not Found`)
- Simulate a backend database using Python dictionaries

### 🛠 Concepts

- `jsonify()`
- URL Parameters
- Dictionary as Mock Database
- GET Request
- HTTP Status Codes (`200`, `404`)
- JSON API Response Design

---

# 02. List JSON Response

Return a list of technologies as a structured JSON response using Flask's `jsonify()` function.

### ✨ Features

- Return JSON list data
- Include response metadata
- Calculate total item count
- Structured API response
- HTTP `200 OK` success response

### 🛠 Concepts

- `jsonify()`
- List Serialization
- Response Envelope
- GET Request
- HTTP Status Code `200`
- JSON API Design
