# 🎬 Coding Learning Hub

A modern YouTube-inspired coding learning dashboard built using HTML5 and CSS3. This project features a stylish sidebar navigation layout, responsive video cards, hover animations, and a clean learning platform UI.

## 🚀 Live Demo

You can view the live project here:
👉 https://akashraval3709-prog.github.io/Python-to-Cyber-Journey/

---

## ✨ Features

* YouTube-style sidebar navigation
* Responsive Flexbox layout
* Modern gradient background
* Interactive hover effects
* Coding course video cards
* External YouTube course links
* Clean and beginner-friendly UI
* Responsive content section
