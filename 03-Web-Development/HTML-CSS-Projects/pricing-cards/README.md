# 📊 Pricing Cards Layout

A beautiful, responsive, and modern **Pricing Cards** layout built using HTML5 and CSS3. This project includes gradient backgrounds, custom Google Fonts, and attractive hover effects for a premium user interface experience.

## 🚀 Live Demo

You can view the live project here:  
👉 [Live Project Link](https://akashraval3709-prog.github.io/Python-to-Cyber-Journey/03-Web-Development/HTML-CSS-Projects/pricing-cards/)

---

## ✨ Features

* **Clean & Modern UI:** Premium-looking pricing cards layout using Flexbox.
* **Smooth Hover Animations:** Interactive hover effects with smooth scaling and color transitions.
* **Highlighted Pro Plan:** The "Pro" pricing card is visually emphasized with larger size and special styling.
* **Fully Responsive:** Uses `flex-wrap` to adapt beautifully across different screen sizes.

---

## 🛠️ Technologies Used

* **HTML5:** For webpage structure and content.
* **CSS3:** For custom styling, Flexbox, gradients, and animations.
* **Google Fonts:** Uses "Google Sans" font for a clean and modern appearance.
