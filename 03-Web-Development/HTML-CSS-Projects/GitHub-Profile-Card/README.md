# 💻 GitHub Profile Card

A modern HTML & CSS project that recreates a stylish GitHub-inspired developer profile card with responsive design and interactive UI elements.

## 🚀 Live Demo

You can view the live project here:  
👉 https://akashraval3709-prog.github.io/Python-to-Cyber-Journey/

---

## ✨ Features

- Responsive profile card layout
- Circular profile image
- Developer username and bio section
- Contribution and streak statistics cards
- Floating contact button
- Hover effects on statistics cards
- Clean dark-themed UI design
- Beginner-friendly frontend project

---

## 🛠️ Technologies Used

- HTML5
- CSS3

---

## 📚 Learning Concepts

- HTML Structure
- CSS Styling
- Card UI Design
- Responsive Layout
- Positioning (`absolute` & `fixed`)
- Hover Effects
- Typography Styling
- Border Radius
- Box Shadow
- Flex-like Layout using `inline-block`
